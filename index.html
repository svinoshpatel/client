Секція 1 — Теги тексту

Теги h1, h2, h3 використовуються для заголовків різних рівнів і створюють ієрархічну структуру документа. h1 — головний заголовок сторінки (один на сторінку), h2 — заголовки основних розділів, h3 — підрозділи всередині h2.
Тег p використовується для абзаців тексту.
Тег strong виділяє текст жирним шрифтом, em — курсивом.
br ставить розрив тексту, тобто текст після нього переноситься на новий рядок. 


<h1>Заголовок документу</h1>
<h2>Розділ</h2>
<h3>Підрозділ</h3>
<p>Абзац тексту</p>
<p><strong>Жирний абзац тексту</strong></p>
<p><em>Абзац тексту курсивом</em></p>
<p>Розбитий<br> абзац тексту</p>

Секція 2 — Списки

Теги ul, ol використовуються для створення списків. ul — невпорядкований список, ol — впорядкований список.
Тег li відповідає за елемент списку. 


<ul>
	<li>елемент 1</li>
	<li>елемент 2</li>
</ul>
<ol>
	<li>елемент 1</li>
	<li>елемент 2</li>
</ol>
  • елемент 1
  • елемент 2
  1. елемент 1
  2. елемент 2

Секція 3 — Посилання та зображення

Тег a використовується для створення гіперпосилань. Атрибут href вказує URL-адресу, куди веде посилання. Атрибут target="_blank" відкриває посилання в новій вкладці.
Тег img використовується для вставки зображень. Атрибут src вказує шлях до зображення, а alt — альтернативний текст, який відображається, якщо зображення не завантажилося. 


<a href="https://example.com">Звичайне посилання</a>
<a href="https://example.com" target="_blank">Посилання в новій вкладці</a>
<img src="image.jpg" alt="Опис зображення">
Звичайне посилання
Посилання в новій вкладці

Секція 4 — Таблиці

Тег table створює таблицю. Тег tr визначає рядок таблиці.
Тег th використовується для заголовків стовпців (автоматично виділяється жирним).
Тег td використовується для звичайних комірок з даними. 


<table>
	<tr>
		<th>Заголовок 1</th>
		<th>Заголовок 2</th>
	</tr>
	<tr>
		<td>Комірка 1</td>
		<td>Комірка 2</td>
	</tr>
	<tr>
		<td>Комірка 3</td>
		<td>Комірка 4</td>
	</tr>
</table>

Секція 5 — Форми

Тег form створює форму для введення даних. Тег label описує поле вводу (атрибут for має співпадати з id поля input).
Тег input створює поле для введення. Атрибут type визначає тип поля (text — текст, email — електронна пошта).
Тег button створює кнопку для відправки форми. 


<form>
	<label for="name">Ім'я:</label>
	<input type="text" id="name">
	
	<label for="email">Email:</label>
	<input type="email" id="email">
	
	<button>Відправити</button>
</form>




Секція 6 — Box Model

Box Model описує, як елементи займають простір на сторінці. Кожен елемент складається з контенту, padding (внутрішній відступ), border (рамка) та margin (зовнішній відступ). 


.box-example {
	margin: 20px;
	padding: 15px;
	border: 2px solid blue;
}
Цей блок має margin 20px, padding 15px та синю рамку 2px

Секція 7 — Typography

Властивості типографії контролюють зовнішній вигляд тексту: font-size (розмір шрифту), font-weight (товщина шрифту), line-height (висота рядка). 


.text-large {
	font-size: 24px;
	font-weight: bold;
	line-height: 1.5;
}

Секція 8 — Colors & Background

Властивості color (колір тексту), background-color (колір фону) та background-image (фонове зображення або градієнт) визначають кольорову схему елементів. 


.colored-box {
	color: white;
	background-color: #3498db;
}

.gradient-box {
	background-image: linear-gradient(to right, #e74c3c, #f39c12);
}

Секція 9 — Layout (Flex або Grid)

Flexbox та Grid — сучасні системи розміщення елементів. Flexbox використовується для одновимірних макетів (рядок або стовпець), Grid — для двовимірних (рядки і стовпці одночасно).

Приклад Flexbox:


.flex-container {
	display: flex;
	gap: 10px;
	justify-content: space-between;
	align-items: center;

Секція 10 — Псевдокласи та hover-ефект

Псевдокласи дозволяють стилізувати елементи в певних станах. :hover спрацьовує при наведенні миші, :focus — при фокусі на елементі (наприклад, клік на поле вводу). 


.hover-button:hover {
	background-color: #27ae60;
	transform: scale(1.05);
}

.focus-input:focus {
	border-color: #3498db;
	outline: none;
}


Секція 11 — Додавання контенту на сторінку (DOM)

JavaScript дозволяє динамічно додавати елементи на сторінку. Використовуємо document.createElement() для створення елемента, textContent для встановлення тексту, та appendChild() для додавання елемента в DOM. 


// script.js
const addButton = document.getElementById('add-text-btn');
const container = document.getElementById('text-container');

addButton.addEventListener('click', () => {
	const newParagraph = document.createElement('p');
	newParagraph.textContent = 'Новий абзац тексту';
	container.appendChild(newParagraph);
});

Секція 12 — Подія та зміна стилю

JavaScript може змінювати CSS-стилі елементів через властивість style або додавати/видаляти класи через classList. Події (events) дозволяють реагувати на дії користувача.

Показати/сховати пояснення


// script.js
const explanationToggle = document.getElementById('explanation-toggle');
const explanationText = document.getElementById('explanation-text');

explanationToggle.addEventListener('click', () => {
	if (explanationText.style.display === 'none') {
		explanationText.style.display = 'block';
		explanationToggle.textContent = 'Сховати пояснення';
	} else {
		explanationText.style.display = 'none';
		explanationToggle.textContent = 'Показати пояснення';
	}
});

Ця функція перемикає видимість елемента, змінюючи властивість display між none та block.
